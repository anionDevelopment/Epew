# Findings handling

The rules for how findings are handled in this repository (where they are collected, how their ids
and columns are formed, how their state is determined and how the findings-section is formatted) are
defined in the OpenSpec-specification
[`common-projects-structure-architecture`](../../openspec/specs/common-projects-structure-architecture/spec.md),
in the requirements about findings.

That specification is the single source of truth for these rules; this document intentionally does
not repeat them, so that the rules can not diverge between two places.
