# Release notes

## Changes

- Fixed nullable-reference-warnings reported by the linting of the `Epew`-codeunit.
- Corrected the commandline-arguments and exitcode documentation in the ReadMe, which no longer matched the actual CLI.
- Completed the codeunit's ReadMe.md and the reference-content placeholders, and fixed a case-sensitivity bug in the reference's navigation (`api/` vs. the generated `API/`-folder).
- Added doc-comments for the non-trivial execution-logic (`ProgramStarter.Main`, `RunBase.Run`/`RunImplementation`, both runners).
- Added testcases for the `RunFile`-verb, base64-encoded arguments and the defined failure-behavior for an invalid workingdirectory, invalid base64-input and missing required arguments.
- Added a findings-handling specification and a `## Findings`-section in the repository-reference to collect code-review-, security- and bug-findings centrally.
- Removed an unused retrieval of the full command line (which needlessly held the complete invocation, including a possibly given password, in memory) from the CLI-runner.
